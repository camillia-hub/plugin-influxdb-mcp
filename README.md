# InfluxDB MCP

Queries InfluxDB time series. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/influxdb-mcp

Installs from the Camillia hub as `influxdb-mcp-2a0173`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
